# GoodKota Visible UI Rollup

v6.1.1 corrects the gap between the v6.1 feature implementation and the interface the user actually sees.

The visible application now uses a stronger GoodKota orange identity without flooding every screen with orange. The main header has a branded orange zone, the Customer home opens with a prominent GoodKota hero, selected/active navigation states use the brand colour, and merchant cards carry restrained orange hierarchy.

Actor separation is visible immediately below the header. Customer, Merchant, Driver, Delivery Ops, GoodKota Admin and GoodKota Owner each show a concise current-context strip. Merchant, Driver and Delivery Ops use purpose-built workspace heroes. Admin uses an orange platform-operations hero; Owner uses a darker company-governance hero so the authority distinction is apparent before reading controls.

The Merchant workspace visibly exposes full order opening, menu add/edit/visibility, settlement, GoodKota support and printable storefront QR access. The public website remains the separate brand/content surface for Kota Culture, promotions, customer waitlist, merchant applications, driver applications and configured social channels.

The UI retains the existing restraint rules: one clear primary action where possible, secondary controls grouped rather than duplicated, and stable modal behaviour without page zooming/scaling.
